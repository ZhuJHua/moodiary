# Contributing to Moodiary

Want to contribute to Moodiary? Start with the **[developer guide](https://docs.moodiary.net/dev/)**, and read the [AI contribution policy](https://docs.moodiary.net/dev/ai-policy) before using AI tools.

想参与贡献？请先阅读 **[开发者指南](https://docs.moodiary.net/zh/dev/)**；使用 AI 工具前请阅读 [AI 贡献政策](https://docs.moodiary.net/zh/dev/ai-policy)。
