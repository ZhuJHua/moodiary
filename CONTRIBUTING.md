# Contributing

Moodiary is licensed under [AGPL-3.0](LICENSE). Setup, conventions and workflow are in the [contributor docs](https://docs.moodiary.net/dev/) ([中文](https://docs.moodiary.net/zh/dev/)).

## Contributor License Agreement

Before your first pull request can be merged, you need to sign the [Contributor License Agreement](CLA.md). A bot prompts you on the pull request, and you only need to sign once per CLA version.

You keep the copyright in your work. The CLA lets the project distribute your contribution, including through the Apple App Store, whose terms conflict with AGPL-3.0 on their own.

## Third-party code

- Do not add dependencies or copy code under GPL, AGPL or LGPL, or code with no license. They cannot ship through the App Store.
- Say where any third-party code or asset comes from, and what license it has, in your pull request.

# 参与贡献

Moodiary 基于 [AGPL-3.0](LICENSE) 开源。环境配置、代码规范和开发流程见[贡献者文档](https://docs.moodiary.net/zh/dev/)。

## 贡献者许可协议

首个 Pull Request 合并前，需要先签署[贡献者许可协议](CLA.md)。机器人会在 Pull Request 上提示你，每个 CLA 版本只需签署一次。

你的作品版权仍归你所有。CLA 让项目可以分发你的贡献，包括通过 Apple App Store 分发，因为 App Store 的条款本身与 AGPL-3.0 冲突。

## 第三方代码

- 不要添加 GPL、AGPL、LGPL 许可的依赖或代码，也不要添加没有许可证的代码。这些内容无法通过 App Store 分发。
- 如果包含第三方代码或素材，请在 Pull Request 中说明来源和许可证。
