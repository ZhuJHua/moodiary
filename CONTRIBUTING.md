# Contributing

Moodiary is licensed under [AGPL-3.0](LICENSE). Setup, conventions and workflow are in the [contributor docs](https://docs.moodiary.net/dev/) ([中文](https://docs.moodiary.net/zh/dev/)).

## Contributor License Agreement

Before your first pull request can be merged, you need to sign the [Contributor License Agreement](CLA.md). A bot posts a link on the pull request. Sign there with your GitHub account. You only need to sign once per CLA version.

In short, you keep the copyright in your work, and you let the project distribute it under AGPL-3.0 and under other license terms. That is what allows Moodiary to ship through the Apple App Store, whose terms conflict with AGPL-3.0. This summary is not part of the agreement.

If your employer has rights in your work, get its approval first. If it needs to sign, open an issue and we will arrange the entity version of the agreement. If you are under 18, have a parent or guardian sign.

## Work you do not own

- Do not add dependencies or copy code under GPL, AGPL or LGPL, or code with no license. They cannot ship through the App Store.
- If your pull request includes third-party code or assets, state where they come from and what license they have, and mark them clearly as not your own.

# 参与贡献

Moodiary 基于 [AGPL-3.0](LICENSE) 开源。环境配置、代码规范和开发流程见[贡献者文档](https://docs.moodiary.net/zh/dev/)。

## 贡献者许可协议

首个 Pull Request 合并前，需要先签署[贡献者许可协议](CLA.md)。机器人会在 Pull Request 上贴出链接，用 GitHub 账号签署即可。每个 CLA 版本只需签署一次。

简单来说：作品版权仍归你所有，你允许项目按 AGPL-3.0 及其它许可条款分发它。正因如此，Moodiary 才能通过条款与 AGPL-3.0 冲突的 Apple App Store 分发。这段说明不属于协议内容，以[英文协议](CLA.md)为准。

如果你的雇主对作品享有权利，请先取得其批准；如需以公司名义签署，请开 issue，我们会安排实体版协议。未满 18 岁请由父母或监护人签署。

## 不属于你的作品

- 不要添加 GPL、AGPL、LGPL 许可的依赖或代码，也不要添加没有许可证的代码。这些内容无法通过 App Store 分发。
- 如果 Pull Request 包含第三方代码或素材，请说明来源和许可证，并明确标注它们不是你的作品。
